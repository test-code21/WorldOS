# WorldOS — Founding Pack

**Status:** Canonical founding package  
**Project:** WorldOS  
**Project class:** First-class canonical OS project  
**Development model:** Generic, public-first, open source  
**Primary implementation direction:** GCP-native and reusable as a SourceLedger capability/plugin

## Founding sentence

> **WorldOS records what a source communicates and preserves enough context to let another system reason about it later.**

WorldOS exists to make the world's publicly available information **machine-readable without severing it from its source**.

It is not itself a world model, geopolitical judge, truth engine, country-rating system, or opinionated intelligence analyst.

WorldOS handles the public information substrate.

Downstream systems may reason over that substrate:

- **IntelOS** can retrieve and orchestrate relevant information.
- **ModelOS** can select models/runs to analyze it.
- **LifeOS** can use those analyses for personal decisions.
- **AiBC/client systems** can use those analyses for commercial or operational questions.
- **SourceLedger** can provide the governed client foundation into which WorldOS is deployed.

## Core separation

**WorldOS**
→ public-world information flow

**SourceLedger**
→ governed private/client source environment

**IntelOS + ModelOS**
→ reasoning and analysis

## Why text first?

WorldOS begins with current textual public sources because text is:

- extraordinarily information-dense per bit;
- abundant across governments, companies, universities, media, institutions, and the open web;
- naturally timestamped and attributable;
- comparatively cheap to preserve;
- and the native medium that modern language models are especially well suited to process.

This is the wedge, not the limit.
