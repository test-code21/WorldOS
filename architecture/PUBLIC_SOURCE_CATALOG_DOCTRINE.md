# Public Source Catalog Doctrine

WorldOS should observe **explicitly configured sources**, not autonomously roam the web during the first decade.

## Why curation

Curated sources provide:
- inspectability;
- predictable load;
- easier legal/policy review;
- transparent coverage;
- community review;
- stable adapter requirements;
- protection against accidental source-popularity bias from search engines.

## Catalog entry should describe

- stable source identifier;
- name;
- canonical URL/location;
- source class;
- jurisdiction reference where known;
- declared language(s) where known;
- adapter;
- preservation mode;
- default cadence suggestion;
- enabled-by-default status in a reference bundle;
- notes required for operation, not ideological characterization.

## Global baseline

The reference project should target transparent coverage across UN member states while retaining a generic jurisdiction mechanism capable of representing other/disputed/partially recognized entities without forcing WorldOS to settle recognition disputes.

## What "coverage" means

Coverage is not merely one URL per country. The mature reference catalog should disclose:
- number of configured sources;
- source classes represented;
- languages represented/declared;
- freshness;
- health;
- known gaps.

## Contribution principle

A contributor should be able to improve their own country's catalog without needing to contribute an interpretation of that country.
