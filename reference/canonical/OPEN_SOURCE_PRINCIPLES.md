# WorldOS — Open Source Principles

## 1. Why open source

WorldOS's primary raw material is publicly available information.

Its core contribution is the machinery that makes that information more durable, structured, attributable, and machine-readable.

That machinery benefits from public inspection.

## 2. Canonical implementation

The public repository is not a demo or reduced edition.

It is the canonical generic implementation.

AiBC may later operate hosted, managed, private, specialized, or commercial deployments based on the same core.

## 3. No preferred country

WorldOS does not encode a favored country or geographic center.

A country-specific consumer can use WorldOS heavily without changing what WorldOS itself is.

## 4. No preferred narrator

WorldOS should not require contributors or users to accept a preselected set of favored media outlets, governments, institutions, or ideological viewpoints.

The system should preserve source identity and context rather than convert publisher preference into hidden truth logic.

## 5. Contributor responsibility

Contributors should distinguish between:

- changes that improve the information machinery;
- changes that embed their own interpretation of the world.

The first belongs naturally in WorldOS.

The second usually belongs in a downstream model or application.

## 6. Inspectability

Important transformations should be testable.

Where model-assisted extraction is used, the project should preserve enough lineage to understand:

- which source was processed;
- which transformation ran;
- what structured output was produced;
- and, where practical, which model/version created it.

## 7. Commercial use

Open source does not prevent commercialization.

Potential commercial value may exist in:

- managed hosting;
- client deployment;
- private SourceLedger integration;
- operational support;
- specialized collectors;
- enterprise governance;
- domain-specific analytical systems;
- custom model runs;
- and integration with broader AiBC infrastructure.

The public project should not be deliberately degraded to manufacture that value.

## 8. Governing sentence

> **We are not open-sourcing our worldview.**
>
> **We are open-sourcing machinery for making the public world computationally accessible.**
